# Personal Mastery OS

A suite of 4 agentic skills and cognitive workflows for self-education, systems thinking, original writing, and executive coaching.

Independent task-scoped plugin, version 1.0.0. Repository: [Leotus-Richard/personal-mastery-os](https://github.com/Leotus-Richard/personal-mastery-os).

## Skills

| Skill | Slash Triggers | Description |
| --- | --- | --- |
| [university-in-a-box](skills/university-in-a-box/SKILL.md) | `/alter`, `/actor`, `/trap` | Self-education curriculum builder, deep reading engine, and durable memory retention loop. |
| [first-principles-systems](skills/first-principles-systems/SKILL.md) | `/dare`, `/dart`, `/aim` | First-principles problem decomposition via AIM constraints and systems diagnostic. |
| [voice-edge-creator](skills/voice-edge-creator/SKILL.md) | `/voice`, `/edge` | Anti-slop writing pipeline and creative concept differentiation. |
| [high-performance-coach](skills/high-performance-coach/SKILL.md) | `/brakes`, `/proof`, `/care`, `/lead` | Executive resilience, anti-burnout triage, self-trust calibration, influence, and leadership coaching. |

## Installation and compatibility

Discover releases through [AI-Plugin-MarketPlace](https://github.com/Leotus-Richard/AI-Plugin-MarketPlace). This repository includes the portable manifest and Codex/Claude compatibility manifests. Host adapters are generated and validated separately by release tooling (`scripts/build_release.py`). Cursor IDE/Agent CLI, Gemini CLI, and Antigravity IDE/CLI require their documented host import path and behavioral validation.

Install only this package when this capability is needed. No sibling plugin, global installer, remote tracker, or background daemon is required.

## Scope and validation

No hooks, background services, automatic delegation, desktop runner, or schedulers are installed. Host-specific examples are reference data, not permission to execute actions.
